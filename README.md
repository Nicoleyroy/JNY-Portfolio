# Joanna Nicole P. Yroy Portfolio

React and Vite developer portfolio.

## Edit portfolio content

Update the name, headline, contact details, skills, and project details in `src/data.js`.

- Add a portrait: replace the JNY composition in `src/App.jsx`, or import an image and add it to the portrait frame.
- Add screenshots: place image files in `src/assets/`, import them in `src/data.js`, and set each project's `screenshot` field.
- Add project links: set `github` and `demo` values in `src/data.js`.
- Add contact details: set `portfolio.contact.email`, `github`, `linkedin`, and `resume` in `src/data.js`.
- Add a résumé: place the PDF in `public/` and set `resume` to a public path such as `/joanna-yroy-resume.pdf`.

## Commands

- `npm run dev`
- `npm run build`
